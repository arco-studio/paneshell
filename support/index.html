サポート

Paneshell は、SSH で Mac やサーバーに接続し、tmux のセッションの中で Claude Code や Codex などを操作するための iOS アプリです。

お問い合わせ

不具合のご報告やご要望は、paneshell.support@gmail.com までお送りください。

お問い合わせの際は、iOS のバージョン、本アプリのバージョン（設定 → このアプリについて）、起きたことと操作の手順をお知らせください。パスワードや秘密鍵は送らないでください。

よくある質問

接続できません。

接続先で SSH サーバーが動いているか、ホスト名・ユーザー名・ポートが正しいかを確認してください。ホスト編集画面の「接続テスト」で、原因が表示されます。

公開鍵認証で接続するには？

設定 → SSH鍵 で鍵を生成し、表示された公開鍵を接続先の ~/.ssh/authorized_keys に追加してください。

パスワード認証で「受け付けていません」と表示されます。

接続先の /etc/ssh/sshd_config で PasswordAuthentication yes になっている必要があります。キーボードインタラクティブ認証には対応していません。

Tailscale SSH を使うには？

この iPhone で Tailscale を接続し、接続先で tailscale up --ssh を有効にしてください。ACL で追加の確認（check）が必要な場合は、接続時に表示される「ブラウザで認証する」から承認してください。Mac の App Store 版 Tailscale は Tailscale SSH のサーバーにならないため、Mac には公開鍵またはパスワード認証で、MagicDNS の名前を使って接続してください。

tmux の中でスクロールするには？

ターミナルを1本指で下になぞると、過去の出力をさかのぼれます。上になぞって一番下まで戻ると、元の入力に戻ります。

tmux のプレフィックスキーを変えています。

設定 → tmux → プレフィックスキー を「自動（接続先の設定を読む）」にすると、接続先の設定を読み取って合わせます。

送った画像はどこに保存されますか？

接続先の ~/.paneshell/images に保存されます。7日を過ぎたものは、次に画像を送るときに削除されます。

Pro を購入した端末を変えました。

同じ Apple アカウントでサインインし、設定 → Paneshell Pro の「購入を復元」を押してください。

FAQ

I can’t connect.

Check that an SSH server is running on the host and that the hostname, user name, and port are correct. “Test Connection” on the host edit screen shows the cause.

How do I use public key authentication?

Generate a key in Settings → SSH Keys, and add the public key shown to ~/.ssh/authorized_keys on the server.

Password authentication says it is not accepted.

The server needs PasswordAuthentication yes in /etc/ssh/sshd_config. Keyboard-interactive authentication is not supported.

How do I use Tailscale SSH?

Connect Tailscale on this iPhone and enable tailscale up --ssh on the server. If your ACL requires an additional check, approve it from “Authenticate in Browser” shown while connecting. The App Store version of Tailscale for Mac cannot act as a Tailscale SSH server, so connect to a Mac with public key or password authentication using its MagicDNS name.

How do I scroll inside tmux?

Swipe down on the terminal with one finger to go back through earlier output. Swipe up to the bottom to return to the input.

I use a custom tmux prefix key.

Set Settings → tmux → Prefix Key to “Automatic (read from the server)” to read and match the server’s setting.

Where are sent images saved?

In ~/.paneshell/images on the server. Images older than 7 days are deleted the next time you send one.

I switched to a new device after buying Pro.

Sign in with the same Apple Account and tap “Restore Purchases” in Settings → Paneshell Pro.
